# Salesforce Marketing Extension for Krista

## Overview

The **Salesforce Marketing** extension for the Krista platform connects to Salesforce's Marketing Cloud and Campaign Management functionality, enabling automated marketing operations and campaign data management through Krista's intelligent automation platform.

### Key Features

- **Campaign Management** — Access and manage Salesforce marketing campaigns
- **Custom Field Retrieval** — Extract custom field data from marketing objects
- **Entity Operations** — Full CRUD operations on Campaign entities
- **Multiple Authentication Methods** — Support for OAuth 2.0 flows and password authentication
- **Real-time Integration** — Direct API connectivity with Salesforce Marketing Cloud
- **Flexible Configuration** — Adaptable to various Salesforce org configurations

## Installation

This extension can be installed through the Krista platform.

## Usage

Configure the extension through the Krista administration interface.

1. **Create Salesforce Connected App** — Set up OAuth credentials in your Salesforce org
2. **Configure Extension** — Set connection parameters (Client ID, Client Secret)
3. **Authenticate Connection** — Establish secure OAuth 2.0 connection
4. **Test Integration** — Verify functionality via the Diagnostics panel

For detailed setup instructions, catalog requests, and API documentation, see the [extension documentation](salesforce_marketing/src/main/resources/documentation/README.md).
